# Egg Dario 3D (鸡蛋达里奥倒立头转)

Interactive Three.js 3D headspin animation of Egg Dario on a wooden desk, with touch orbit/pinch-zoom, mode switching (Full Loop / Endless Turbo / Face Check), 180° camera flip, and speed control.

- Live 3D Page: `index.html`
- Standalone SVG Animation: `egg-dario-spin.svg`
- Source: `src/main.js` (`node build.mjs` to rebuild)
